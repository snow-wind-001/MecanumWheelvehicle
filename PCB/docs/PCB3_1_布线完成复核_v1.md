## 必须随制板文件提供的工艺要求

本版包含焊盘内过孔及驱动器散热孔。**所有 VIA 过孔按树脂填孔、整平并铜盖帽处理（VIPPO / POFV）；插件焊接孔不填充。** 本板 VIA 标称孔径为 8/12 mil（0.2032/0.3048 mm）。普通盖油不能替代本版焊盘内过孔的填孔盖帽要求。表面处理建议 ENIG。

孔位见 [填孔盖帽孔位表](../bom/PCB3_1_填孔盖帽孔位表_v1.csv)。坐标采用 PCB 编辑器原点和毫米单位，制造定位以最终钻孔文件及该表为准。工艺依据：[嘉立创过孔覆盖与填孔说明](https://jlcpcb.com/help/article/pcb-via-covering)。
