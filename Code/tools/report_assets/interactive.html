    ## 算法图解与麦轮交互演示 {#algorithm-demo} ### ① 车体速度 → 四轮目标：和 vc_inverse() 对照 拖动速度滑杆，观察轮组方向、速度和限幅。轮序为 FL、FR、RL、RR；图中前方朝上，横向正方向朝右，wz 正方向采用固件内部逆时针约定。展示的是 `vehicle_control.c` 的内部输入，不是未经转换的 ROS 消息。示例几何与轮速上限只是演示参数，不能替代车辆标定。

    演示半轴距 L=0.15 m、半轮距 W=0.12 m、ωmax=20 rad/s。仅展示逆解与统一限幅，斜率限制和 PI 在后面的闭环图说明。

    条纹正反转是方向示意，未模拟滚子接地、滑移或实际车速。

    k = L + W，原始轮速：

    ωFL = (vx − vy − k·wz) / r     ωFR = (vx + vy + k·wz) / r
ωRL = (vx + vy − k·wz) / r     ωRR = (vx − vy + k·wz) / r

    ### ② 编码器 → 斜率限制 → PI → 输出：闭环结构
    1. 回绕与滤波：Δcount 按 16/32 位模数求差，ωraw=Δcount·2π/(CPR·dt)，α=dt/(τ+dt)，ωfiltered←ωfiltered+α(ωraw−ωfiltered)。
    2. 同步斜率：先求四轮最大目标差，使用同一个 ratio=min(1, αmax·dt/max|ωdesired−ωtarget|) 缩放各轮更新量，避免各轮单独裁剪破坏速度比例。
    3. 换向保护：目标方向改变而实测速度仍高于换向阈值时先输出零；允许改向时也有一个清积分/零输出周期。
    4. PI 与前馈：按目标方向控制幅值；积分是否接受取决于输出是否饱和及误差是否帮助退出饱和。最终再检查实际联锁。
